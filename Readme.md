# Machine Learning Models

This repository contains practical implementations of machine learning algorithms, organized into two main categories:

### 1. Supervised Learning
Covers algorithms that learn from labelled datasets to make predictions and classify new observations. Includes regression and classification models.

### 2. Unsupervised Learning
Covers algorithms that work with unlabelled datasets to discover hidden patterns, group similar observations, identify anomalies, and reduce dimensionality.

Each folder contains individual notebooks with algorithm explanations, implementation, and evaluation.

## Tools & Libraries
Python, NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.
